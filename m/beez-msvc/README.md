# msvc

MSVC compile and link steps from compile_commands.json.

## Install

From the Beez plugin catalog:

```bash
rqp install beez coditary/msvc@1.0.0
```

From this directory via `build.lua`:

```lua
reqpack {
  beez = {
    {
      name = "coditary/msvc",
      version = "1.0.0",
      path = ".",
    },
  },
}
```

Then: `beez --install`

## Usage

Requires a configured CMake/Conan build tree with `compile_commands.json`.

```bash
beez build                    # msvc:compile then msvc:link
beez -s coditary/msvc:msvc:compile
beez -p compile[msvc]
```

Set `CC=cl` and `CXX=cl` (defaults) to override the compiler binary used when replaying compile commands. Link commands keep `link.exe` from the build environment.

## Visual Studio environment

MSVC tools require the Visual Studio environment. Run Beez from a shell where `vcvarsall.bat` (or equivalent) has been sourced so `cl` and `link` are on `PATH`:

```cmd
"C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvarsall.bat" x64
beez build
```

On Windows with Git Bash or WSL cross-builds, ensure the same environment variables are visible to the shell scripts generated by this plugin.

## Steps

| Step | Phase | Scope | Description |
|------|-------|-------|-------------|
| `msvc:compile` | compile | msvc | Compile sources from compile_commands.json |
| `msvc:link` | bundle | msvc | Link binaries under `bin/` |
